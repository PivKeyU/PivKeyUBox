# 片刻收纳 · 吉伊系 UI 重设计审阅稿

这是一个隔离的视觉审阅稿，不会替换当前 React 界面或 Windows release。

最新的主角参考稿：打开 `character-icon-review.html`，审阅基于你提供的多张吉伊角色图重新校准、并替换右侧两个动作的 A/B/C/D 四个主图标方向。当前版本资产为 `assets/character-icon-variants-actions.png`；此前的参考一致版和窄长版本保留作对比。

最新的透明角色姿势稿：打开 `transparent-pose-review.html`，可以用颜色选择器实时替换画板背景，审阅 6 个独立的手绘姿势 PNG。文件位于 `assets/poses/`，均已验证为带 Alpha 通道的 RGBA PNG，不会把预览背景写入角色文件。

打开 `chiikawa-ui-review.html` 后可以查看三块画板：

1. 桌面收纳：分区、快捷方式、文件 tile 与标题条。
2. 设置菜单：分类导航、开关、滑杆、分段选择与分类图标选择。
3. 系统托盘：与主界面共用同一套图标、圆角和交互反馈。

## 视觉方向

- 吉伊气质的原创圆润小生物，不直接复刻原作素材。
- 奶油、珊瑚、薄荷、粉蓝、奶黄、薰衣草作为语义色。
- 图标以“角色 + 文件语义物件”组合，缩小到 20–48px 仍可识别。
- 保留 Maple Mono-NF-CN，设置页优先使用清晰的信息层级，不用大面积玻璃和复杂渐变。
- 互动控件保留键盘焦点、ARIA 名称、减少动态效果支持。

## 审阅重点

请优先确认：

- 角色表情是否足够可爱但不过度抢占文件信息。
- 奶油底色与珊瑚强调色是否适合长期使用。
- 设置页的左侧分类、卡片分组和控件密度是否舒服。
- 托盘菜单是否与主界面统一，是否需要更紧凑或更活泼。

确认后再进入第二阶段：把图标拆分成正式资源、接入 React 组件、同步原生托盘菜单，并重新打包 release。
